# تطبيق وحي ونماء — المعلم (`mobile/teacher-app`)

تطبيق **React Native (Expo + TypeScript)** مخصص لمعلمي ومعلمات أكاديمية **وحي ونماء**، ومربوط بالكامل بنفس واجهات برمجة التطبيقات (`https://api.wahywanamaa.com`) والموقع الرسمي (`https://wahywanamaa.com`)، ومهيأ لإخراج ملف **Android APK** مباشر للتثبيت اليدوي على الهواتف الآن، مع جاهزية كاملة لاحقاً لـ **Google Play (AAB)** و**App Store (iOS)**.

## المميزات المدمجة بالكامل
- **تسجيل دخول المعلم والتحقق من الدور**: يمنع دخول غير المعلمين، ويعرض بوابة حالة الاعتماد (`TeacherApprovalGate`) للمعلمين قيد المراجعة أو الذين يحتاجون استكمال بيانات.
- **الرئيسية والإحصائيات الحية**: الحصة القادمة مع زر دخول فوري للقاعة المباشرة، تنبيهات الطلبات المعلقة والواجبات المسلمة، مؤشرات الأداء السريعة.
- **إدارة الحصص والطلبات**: قبول / اعتذار بسبب / اقتراح موعد جديد، تحضير طلاب الحلقات الجماعية، إنهاء وتقييم الحصص الفردية والتجريبية والجماعية مع إرسال التقرير وإسناد الواجب تلقائياً.
- **القاعة المباشرة داخل التطبيق (`LiveKit`)**: دخول قاعة الحلقة والمصحف المتزامن مباشرة داخل التطبيق دون فتح متصفح خارجي.
- **المحادثة الفورية للحصص**: إرسال واستقبال الرسائل النصية وتشغيل الرسائل الصوتية.
- **الطلاب والحلقات الجماعية**: ملف تقدم الطالب القرآني، حلقاتي الجماعية، جدولة حصص جماعية جديدة.
- **الواجبات والملاحظات الصوتية**: الاستماع لتسجيلات تلاوة الطلاب، تسجيل تعليق صوتي مباشر بصوت المعلم، اعتماد الواجب أو طلب إعادة، وإسناد واجبات جديدة لطالب أو لحلقة كاملة.
- **المحفظة وسحب الأرباح**: أرصدة الجنيه المصري والدولار الأمريكي، سجل المعاملات، وتقديم طلب سحب (فودافون كاش / إنستا باي / تحويل بنكي / PayPal).
- **الجدول الأسبوعي**: إضافة وحذف فترات التفرغ الأسبوعية وحفظها مباشرة على الموقع.
- **رسائل وتوجيهات للطلاب**: نشر تنبيهات لكل الطلاب النشطين أو طلاب محددين، وحذفها.
- **الإحصائيات وتقييمات الطلاب والإشعارات والملف الشخصي**: تقارير شهرية، تقييمات الطلاب المعتمدة، صندوق الإشعارات، وطلب تعديل الملف العام مع رفع صورة جديدة.
- **التحديث التلقائي (`UpdateGate`)**: يدعم تحديثات **OTA (Expo Updates)** وكذلك بوابة إصدارات الـ APK عبر `/api/mobile/config?app=teacher`.

## التشغيل المحلي للتجربة
```bash
cd mobile/teacher-app
npm install
npx expo start
```

## إخراج ملف `.apk` مباشر للتثبيت اليدوي على الأندرويد
1. ثبت أداة EAS وسجل الدخول:
   ```bash
   npm install -g eas-cli
   eas login
   ```
2. اربط المشروع بحساب Expo (أول مرة فقط):
   ```bash
   cd mobile/teacher-app
   eas init
   ```
3. ابنِ ملف الـ APK:
   ```bash
   npm run build:apk
   ```
4. عند اكتمال البناء، يعطيك EAS رابط تحميل مباشر لملف `Wahy-Wa-Namaa-Teacher.apk` جاهز للتثبيت اليدوي على هواتف المعلمين.

## ربط رابط التحميل المباشر بالموقع
ارفع ملف الـ APK في GitHub Releases باسم `Wahy-Wa-Namaa-Teacher.apk` أو اضبط المتغيرات التالية في بيئة الباك إند (Vercel):
```env
MOBILE_TEACHER_LATEST_VERSION=1.0.0
MOBILE_TEACHER_MIN_VERSION=1.0.0
MOBILE_TEACHER_ANDROID_APK_URL=https://github.com/hamyn203-commits/wahy-wa-namaa-academy-/releases/latest/download/Wahy-Wa-Namaa-Teacher.apk
```
سيعمل زر **تحميل تطبيق المعلم (APK)** في صفحة `/ar/app` بالموقع تلقائياً عبر `/api/mobile/download/android?app=teacher`.

## التحديثات الفورية بدون APK جديد (OTA)
```bash
cd mobile/teacher-app
npm run publish:ota -- "وصف التحديث"
```

## فحص الأنواع (`TypeScript`)
```bash
cd mobile/teacher-app

```
